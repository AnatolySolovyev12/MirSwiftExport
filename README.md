What can:

1) Allows you to output to the CLI already read out the current A+ tariff readings from all devices that are in the configuration along with the device serial number.
2) When reading, it screens out those devices for which readings have not been obtained. It also screens out incorrect readings. Incorrect devices are discarded, including.
3) Allows you to massively rename predefined points in a serialized configuration for subsequent reading. The first two columns of the document are imported from Excel.

Что умеет:

1) Позволяет вывести в CLI уже считанные текущие тарифные показания А+ со всех устройств которые имеются в конфигурации вместе с серийным номером устройства.
2) При считывании производит отсев тех устройств для которых показания не были получены. Также производит отсев некорректных показаний. Некорректные устройства отбрасываются в том числе.
3) Позволяет массово переименовывать заранее заведенные точки в конфигурации с присвоением серийных номеров для последующего считывания. Импорт производится из Excel документа по первым двум столбцам.
